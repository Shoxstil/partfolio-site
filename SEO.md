# Индексация сайта Shoxstil в Google

Основной адрес: https://shoxstil.github.io/partfolio-site/

В странице настроены заголовок, описание, канонический адрес, Open Graph и
структурированные данные ProfilePage/Person. Ник Shoxstil и описание занятий
присутствуют также в видимом тексте. `sitemap.xml` содержит основной адрес;
архивные демо не добавлены как отдельные страницы портфолио.

## После публикации изменений на GitHub Pages

1. Открой https://search.google.com/search-console/ под своим Google-аккаунтом.
2. Добавь ресурс с префиксом URL: `https://shoxstil.github.io/partfolio-site/`.
   Подтверждение домена через DNS для общего домена `github.io` не требуется.
3. Выбери подтверждение HTML-файлом: скачай выданный Google файл, положи его
   без изменений в корень этого репозитория и опубликуй. Проверь доступность
   файла по указанному Google адресу, затем нажми «Подтвердить».
   Альтернатива — выданный Google метатег в `<head>` страницы `index.html`.
   Не удаляй файл или метатег после подтверждения.
4. В разделе Sitemaps отправь
   `https://shoxstil.github.io/partfolio-site/sitemap.xml`.
5. Через «Проверку URL» проверь основной адрес, выполни проверку опубликованной
   страницы и запроси индексирование. Если Google сообщает о проблеме, сначала
   исправь её. Повторные ежедневные запросы не ускоряют обработку.

Индексация и позиция не гарантированы и могут занять от нескольких дней до
нескольких недель или дольше. Google может самостоятельно менять заголовок и
описание результата. Разметка Person не гарантирует отдельную карточку человека.

## robots.txt на GitHub Pages

Google читает `https://shoxstil.github.io/robots.txt`, а не
`https://shoxstil.github.io/partfolio-site/robots.txt`. Поэтому файл robots.txt
в этот репозиторий не добавлен. Для общедоступного сайта отсутствие robots.txt
само по себе не запрещает обход. Если управляешь репозиторием корневого сайта
`shoxstil.github.io`, проверь его существующий robots.txt: он не должен запрещать
обход `/partfolio-site/`. В него можно добавить отдельную строку:

```text
Sitemap: https://shoxstil.github.io/partfolio-site/sitemap.xml
```

Не перезаписывай существующие правила вслепую. Отправка карты напрямую через
Search Console работает и без этой строки.

## Профили

Добавь ссылку на сайт в профиль GitHub и описание своего YouTube-канала.
После проверки точного адреса канала можно добавить его в видимый раздел
сайта и массив `sameAs` в JSON-LD. Сейчас в `sameAs` указан только известный
профиль GitHub; адрес канала не угадан. Не добавляй неподтверждённые звания,
рейтинги или достижения.
